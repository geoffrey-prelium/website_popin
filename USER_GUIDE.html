1. Introduction au module

Le module Website Popin & Banner Builder d'Odoo vous permet de créer des outils marketing directement intégrés à votre site web de deux façons :

  • Des Popins (Modals) ou Bannières : Des fenêtres s'affichant par-dessus le contenu pour inciter vos visiteurs à l'action (promotions, newsletter, sortie de page).
  • Des Shared Blocks (Blocs partagés) : Des morceaux de HTML/Contenu (ex: un bloc d'appel à l'action, un footer spécial) que vous pouvez configurer une seule fois dans l'interface et déployer sur plusieurs pages web via l'éditeur "Glisser-Déposer". En modifiant le code source de ce bloc partagé, il se mettra à jour automatiquement sur toutes les pages web où il est affiché.

2. Créer et configurer une Popin

Accès au menu

Allez dans l'application Site Web (Website) > Configuration > Popins & Blocks > Popins & Banners.

Processus de création

  1. Cliquez sur le bouton Nouveau.
  2. Nom : Donnez un titre interne à votre Popin (ex: Promo Hiver 2026).
  3. Publié sur le site web : Pensez à cliquer sur l'icône rouge en haut à droite pour passer le statut de Non Publié à Publié lorsque votre configuration sera terminée. L'interrupteur "Actif" doit également être coché.

Configuration Générale

Champ Description
Type Le format de votre affichage (Bannière fixe en haut/bas, Modal classique au centre, plein écran...).
Campagne UTM (Optionnel) Liez votre popin à une campagne d'acquisition existante pour suivre les statistiques du trafic.
Sites Web Cochez les sites sur lesquels la popin a le droit de s'afficher (idéal en cas de multi-sites B2B/B2C).
Fréquence (Frequency) Contrôle le harcèlement du visiteur :
  • Continuellement : Affiche la popin à chaque fois que la règle est remplie.
  • Jours (days) : Permet de définir combien de jours doivent s'écouler avant de remontrer la popin au même utilisateur.
Type de visiteur Sélectionnez si la popin s'affiche pour "Tout le monde", uniquement pour les personnes non connectées (invités/anonymes) ou uniquement pour vos clients connectés.

Onglet "Contenu" (Content)

Cet onglet contient un éditeur de code. Vous devez y insérer le code HTML strict qui composera le contenu visuel brut de votre Popin (titre, image, lien vers un produit, formulaire de contact).

3. Filtrage et Cible (Onglets Targeting & Triggers)

Les popins ne s'affichent pas partout au hasard. Vous devez configurer quelles pages surveiller (Targeting) et quelle action déclenche l'affichage (Triggers).

Onglet "Targeting" (Où l'afficher ?)

  • Pages : Sélectionnez manuellement les pages spécifiques créées via le constructeur Odoo (ex: /contactus).
  • Articles de blog : Ciblez un article de blog promotionnel spécifique.
  • Motifs d'URL (URL Patterns) : Permet d'afficher la Popin sur des groupes de pages de façon dynamique. Exemple: écrivez /shop/* pour que la popin s'affiche sur la boutique et sur toutes les fiches produits !

Onglet "Triggers" (Quand l'afficher ?)

Type de déclenchement Configuration du comportement
Délai (Delay) S'affiche X secondes après l'arrivée sur la page (renseignez le délai).
Défilement (Scroll) S'affiche quand le visiteur a descendu la page jusqu'à un certain pourcentage (ex: affiche si `trigger_scroll = 50%`).
Clic (Click) Ne s'affiche QUE si l'utilisateur clique sur un module précis de la page (renseignez le sélecteur CSS du bouton).
Intention de sortie S'affiche immédiatement quand la souris du visiteur quitte la zone de la page pour aller vers la croix de fermeture du navigateur.

4. Statistiques et Analytics

Dans l'interface de la Popin, en haut à droite, des "Smart Buttons" comptent automatiquement le nombre d'affichages (Views) et de clics reçus (Clicks).

L'onglet Analytics détaille ces données :

  • Links Performance (Liens) : Si vous avez mis un bouton ou un lien `<a>` dans le HTML de la popin, Odoo tracera combien de clics chaque URL du corps de texte a reçu individuellement.
  • Page Performance (Pages) : Indique sur quelle page précisément la Popin a eu le plus de succès (utile si vous utilisez les filtres globaux de type /shop/*).

5. Les Blocs Partagés (Shared Blocks)

Les Blocs Partagés vous permettent d'injecter facilement un morceau de HTML sur le site grâce à l'éditeur "Glisser/Déposer" standard d'Odoo, sans avoir à copier/coller le code partout.

Étape A : Créer la ressource Bloc Partagé dans le Backend

  1. Dans Site Web > Configuration > Popins & Blocks, cliquez sur Shared Blocks.
  2. Créez un nouveau bloc (ex: "Bandeau Footer Réseaux Sociaux").
  3. Basculez-le en mode Publié en haut à droite (indispensable pour le voir en ligne).
  4. Dans l'onglet Content, collez le code HTML du bloc.

Étape B : Intégrer le Bloc Partagé visuellement sur le site !

  1. Rendez-vous sur n'importe quelle page de votre site web (coté Front-End).
  2. Cliquez sur Éditer (Edit) en haut à droite pour ouvrir le constructeur de site.
  3. Dans la palette des blocs à droite, cherchez dans la section Shared Blocks.
  4. Glissez le bloc "Shared Block" sur la page. Par défaut, un texte bleu informatif apparaît.
  5. Sélectionnez le bloc que vous venez de glisser en cliquant dessus.
  6. Regardez le menu latéral de droite (les "options" du bloc). Vous y verrez un menu déroulant intitulé "Select a Block..." (Choix du bloc).
  7. Sélectionnez le nom du bloc partagé créé à l'étape A (ex: "Bandeau Footer..."). Magie : Le code HTML injecté en Back-end se charge directement dans l'interface visuelle !
  8. Sauvegardez la page de votre site web.
💡 Astuce : Placez ce snippet Shared Block sur 10 pages de votre site et choisissez le même modèle. Si demain vous souhaitez changer une couleur ou une url dans ce bloc, modifiez simplement son code HTML via Site web > Configuration > Shared Blocks : il se mettra à jour instantanément sur vos 10 pages web !
